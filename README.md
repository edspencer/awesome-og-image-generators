# 🖼️ Awesome Social Image Generation

> A curated list of tools for creating **OpenGraph images, thumbnails, title cards, banners, and dynamic social preview images**, both manually and via API.

[![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

Pull requests welcome 🚀

---

## 🎯 No-Code / UI Tools

| Tool                    | Description                                                                                                                               |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| 🚀 **frameit.dev**      | [https://frameit.dev](https://frameit.dev) — Create thumbnails, OG images, title cards & banners in the browser — API support coming soon |
| Placid                  | [https://placid.app](https://placid.app) — Auto-generate marketing images, banners, PDFs                                                  |
| BannerBear              | [https://bannerbear.com](https://bannerbear.com) — Automated image & video generation for social                                          |
| Cloudinary Social Cards | [https://cloudinary.com/social-media-cards](https://cloudinary.com/social-media-cards) — Template OG image generation                     |
| MagicBanner             | [https://magicbanner.ai](https://magicbanner.ai) — AI-based banner & hero image generator                                                 |
| Socialify               | [https://socialify.git.ci](https://socialify.git.ci) — Generates GitHub repo social cards                                                 |
| ShotSnap                | [https://shotsnap.com](https://shotsnap.com) — Screenshot → image styling                                                                 |
| TinyTools              | [https://tinytools-smoky.vercel.app](https://tinytools-smoky.vercel.app) — Free browser-based OG image generator (plus favicon, color palette, SEO meta tag generators) — no signup, runs locally                       |
